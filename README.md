# User Profile Card Generator

A dynamic web application for creating and displaying user profile cards using Node.js, Express, EJS, HTML, CSS, and JavaScript.

## 🚀 Features

- Create dynamic user profiles
- Display profile cards
- Clean and responsive user interface
- Server-side rendering with EJS
- Express.js backend
- Profile data management using JSON
- Secure HTML escaping
- Simple and easy-to-use interface

## 🛠️ Technologies Used

- Node.js
- Express.js
- EJS
- HTML5
- CSS3
- JavaScript
- JSON
